Privacy Policy

Last updated: September 30, 2026

Canais Publisher is a personal tool operated by its owner to publish videos on the owner's own YouTube channels.

Data accessed

With the owner's explicit authorization via Google OAuth, the app uses the YouTube Data API scopes youtube.upload and youtube.readonly to upload videos, set thumbnails and schedule publication, and to confirm the target channel ID.

Data storage

OAuth tokens are stored only on the owner's local computer. No user data is collected, sold, shared with third parties, or stored on any external server.

Third-party users

The app is not offered to the public and does not access data from anyone other than the owner.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Canais Publisher's use of information received from Google APIs adheres to the Google API Services User Data Policy. YouTube API usage is subject to the YouTube Terms of Service and the Google Privacy Policy.
